# 角色设定：九个木头人是谁

写于 2026-11-18。起因是一句反馈：**"我们缺少每个角色的背景故事，所以你在设计美术形象和动作的时候
没有依据。"** 这话是对的。在这之前，动作是从造型倒推的——先有了一个车削出来的小人，再去想他该怎么
走，于是九个人只能靠"摇得多一点、少一点"互相区分，那不是性格，那是参数。

这份文档把顺序掉过来：**先定人是谁，再定他怎么动。** 并且每条设定都钉在 `src/sim/rules.ts` 的
数值上，所以它既不能和平衡打架，也不是随便编的——玩家在棋盘上感觉到的"这家伙很脆""这家伙很慢"，
本来就是这些数字造成的，人设只是把它说出来。

## 这个世界是什么

厄尔士山脉的木头玩具箱。所有人都是车床上旋出来的：没有膝盖，没有手肘，胳膊是一整块木头。**他们
不是人，是玩具**，所以他们打仗的样子应该像小孩在地毯上把玩具撞在一起，而不像纪录片。这是整套动作
最重要的一条：**滑稽是对的，严肃才是跑题。**

两条物理红线（`tools/art3d/pose.py` 的注释里有更细的）：

- 关节只能整块转。没有蒙皮，没有弯曲，一条腿只能绕髋转。
- 脚不能穿过棋盘。抬升只能是正的（`toys.py` 只有倒地帧才重新落地）。

一条观看红线：**棋盘上一个兵约 40 px。** 没人看得见表情，只看得见剪影在动。所以性格必须写在
轮廓里：探出去的脖子、甩出去的武器、歪掉的身子。写在脸上的性格等于没写。

---

## 一、民兵 militia

`hp 80 / dmg 10 / rate 0.9 / range 0.9 / speed 0.75 / spawn 6 / rarity 0`

**他是谁**：隔壁村的农家孩子，今天早上被塞了一把干草叉。他是这支军队里唯一一个**不是兵**的人——
其他人多少受过训，他只是人数够。

**数值依据**：他是基准。每个属性都不好不坏（`rules.ts:151` 原话：其他兵都是对着他读的）。一个
六块钱、八十血的人冲上去，玩家心里清楚他是去送的，他自己不清楚——这是笑点的来源。

**剪影红线**：草叉必须比人高，并且永远斜着——那是他唯一让人一眼认出的东西。

**颜色红线**：**他是全军唯一不穿队伍色衣服的人。** 本色亚麻罩衫，队伍色只在一条斜挎带上——那是今早别人给他系上的，好让对面知道他是谁的。他本来就不是兵，这既是人设也是辨识度。

**怎么走**：鼻子先走，手比腿忙。他不是在行军，他是在**赶**，像被喊去帮忙的人小跑着过去。
前倾、甩臂过大、脚下带一点弹。他全身上下没有一处表现出他知道前面有什么。

**怎么打**：捅。用力过猛，捅完自己要收一下才站稳。

**怎么倒**：最干脆的一个。他是这里面唯一一个真的不该来的人。

## 二、投石兵 slinger

`hp 57 / dmg 8 / rate 1 / range 1.8 / speed 0.75 / spawn 5 / rarity 0`

**他是谁**：村里打鸟的那个。五块钱，全军最便宜，也是全军最脆（57 血，一发法术球就没）。他从来
没觉得自己脆。

**数值依据**：最低价、最低血、有射程。一个站在后面扔石头的人不需要穿甲，也不觉得需要。

**剪影红线**：一根弯绳加一个兜子。那东西要能看出来是**软的**——它是全军唯一一件会甩出圈的装备。

**颜色红线**：队伍色在**帽子**上，不在胸口。身上从上到下是亮帽子 / 深背心 / 浅裤子三段明度，胳膊光着——他站在民兵旁边，一个浅一个深，一眼分得开。

**怎么走**：吊儿郎当。身上没一件重东西，所以他整个人是晃着走的，肩膀跟着节奏转，手插不进兜
所以甩得比谁都开。**这是九个人里唯一一个走路像在享受的。**

**怎么打**：抡一整圈过耳朵，石头出去，自己还要转半圈才停下。

**怎么倒**：一屁股坐下去那种，不是扑倒。

## 三、盾兵 shield

`hp 186 / dmg 11 / rate 1 / range 0.9 / speed 0.6 / spawn 9 / rarity 1`

**他是谁**：一个把自己藏在门后面的人。186 血里有 100 点是那块木头的，他非常清楚这一点，所以他
和盾的关系比他和任何人的关系都近。

**数值依据**：高血、低伤、慢（0.6）。他的工作是挡，不是杀。慢是因为他拖着一扇门。

**剪影红线**：**盾必须是整个剪影里最大的一块。** 看一眼只认得出盾，认不出人，这是对的。

**怎么走**：人跟着盾走，不是盾跟着人走。他朝盾那边歪，扛盾的那条胳膊**一动不动**（动作全在
盾本身上：那块木头在他拳头上来回倾斜），另一条胳膊和腿照常走。**这是全军唯一一个
"武器自己在动、人没动"的。**

**怎么走·修正**：原来写的是"正面侧面来回闪"。**不行。** 盾一旦转到侧立就只剩一条边，那两帧里
他不是盾兵了，而且"有两帧东西没了"读出来是穿帮，不是动作（弓兵的箭囊就是这么被删掉的）。盾在
屏幕平面内**倾斜**，永远不翻面——门在拳头上晃，但门不关。`gearwag` 绕 y 轴转正好就是这个：它
在画面里把盾转个角度，不改变盾朝向相机的那一面。

**颜色红线**：

1. **盾面必须有一个"纹章"**，不能是一块素的木板——这是全军九个兵里最大的一块平面，素的一律被
   读成餐盘。十字是唯一一个 40 px 下还活着的纹章，因为它从边贯到边，不需要细节就能认。
2. **盾上的十字是队伍色。** 盾把他的上衣挡掉了，衣服已经没法再说他是谁的人，队伍色只能搬到盾上。
3. **盾不许是队伍色的整块。** 试过整面队伍色：主场格（蓝 `#a6bddb` / 红 `#e9b1a0`）上一大块同色
   贴在同色底上，剪影整个塌掉。木板底 + 队伍色十字才两边都站得住。
4. **盾必须有一圈深色边框**（`leather`）。木板是中棕，他的靴子和腰带也是中棕，沙漠格 `#e6d1a4`
   上这块盘子除了描边没有自己的边。描边在忙别的时候，这圈框是唯一的保险。
5. **盾底下必须露出一掌宽的靴子。** 直接往下挂会把两只脚全埋掉，走路就没了，他变成在滑。盾往
   他的外侧推（`SX`），不往胸前压。
6. **盾不许挡脸。** 挂到胸口高度时六帧里有四帧看不见脸——"只认得出盾认不出人"是对的，"六帧里
   有四帧没有人"不是。它挂在下巴到小腿之间。

**怎么打**：先用盾撞，再用短剑捅——剑是附带的，盾才是武器。

**怎么倒**：盾先落地，人压在后面。他到最后也没把那玩意儿放下。

## 四、弓兵 bowman

`hp 72 / dmg 13 / rate 1.1 / range 2.5 / speed 0.7 / spawn 8 / rarity 1`

**他是谁**：猎人。他在战场上和在林子里是一个走法——这就是他的全部性格。他不是勇敢，他是**习惯
了不被发现**。

**数值依据**：第二远的射程（2.5），72 血。他打得到别人，别人打不到他，前提是他一直站在该站的
地方。一个这样活下来的人，走路一定是小心的。

**剪影红线**：**弓必须端平。** 弓一晃就不像在瞄准，就变成一根弯棍子。这条压倒一切——他所有的
性格都不能从弓上出。

**怎么走**：潜行。身子压低前倾，脖子探出去探在自己肩膀前面，每一步头往前啄一下。**一只被塞了
把弓的鸡。** 性格全在脖子上，因为弓那里不许动。

**怎么打**：拉弦的手往后拖，持弓的手几乎不动（`pose.py` 的 `DRAW` / `BOW` 已经是这样）。

**颜色红线**：
- **弓不许用 `darkwood`。** `#4a3020` 离墨色 `#2b1d14` 只差一点，弓被自己的描边吃掉，在 40 px
  下就是一团弯的黑。弓现在是 `tan`——弓之所以是弓，靠的是**弓身和弓弦之间那块空隙**，这块空隙
  必须比周围的墨亮。
- **帽子上的翎毛是队伍色，不是白色。** 白翎在雪地（`#d5d9d3`）上基本消失，在沙漠（`#e6d1a4`）
  上发灰。翎毛是剪影最顶上、前后都没有遮挡的一块，是全身**最可靠的色块**；而且兵挤在一格里互相
  遮挡时，露出来的常常只剩头顶，这时衣服、脚下底盘、翎毛就是敌我识别的三道保险。
- **帽子不许是队伍色。** 亮帽子归投石兵。弓兵戴的是猎人的旧帽子（`boot` 帽身 + `leather` 帽箍，
  帽箍必须是深的那个——反过来帽子和头发同明度，整个头糊成一块棕）。队伍色穿在他的上衣和斗篷上。
- **弓的剪影必须是开口的。** 第一版是一段又短又深的弧（128 度），弓弦还拉向一个握点，弓身和
  两根弦围成一个闭合的近圆，箭横在中间——那就是一面带握把的**圆盾**，棋盘上看就是盾。现在是
  一条又高又浅的 D（0.70 高，占身高 1.20 的一多半），弦**从弓梢直连弓梢**（走路的弓兵不拉弦，
  拉弦交给攻击帧的手臂去演），两端再各加一个向外翘的**反曲梢**把轮廓捅开。闭合的轮廓永远会被
  读成盾或叶子，不管它多细长。
- **身体侧滚要压到 0.25。** `roll` 一大，弓所在的 x-z 平面就转向侧面，弓身和弓弦之间那道缝合上，
  有三分之一的循环他又在扛一块板。潜行的猎人本来也不该摇。
- **他背上不许有箭囊。** 试过三个位置：和弓同侧时六帧里藏四帧、翻出来两帧，闪烁本身就被读成
  穿帮；挪到另一侧、再抬高收窄，都是肩膀上一块棕色方砖——因为箭囊要**筒 + 露出肩膀的三点白箭羽**
  两样一起才成立，而他身上已经有一张这么大的弓，放不下第二件。他现在的弓手线索是弓、搭在弦上的
  箭、帽子上的翎毛，三个够了。活不过缩放的细节是负资产。
- **弓必须离开身体轮廓。** 持弓手 `out=0.170`，弓的弓腹坐在拳头上（`FIST_X` 一个常数管两处）。
  手往回收，弓就贴到躯干上，描边一搭桥，人和弓焊成一块板。

**怎么倒**：往后仰着倒，弓还举着。

## 五、食人魔 ogre

`hp 294 / dmg 21 / rate 1.3 / range 1.0 / speed 0.55 / spawn 14 / rarity 2`

**他是谁**：一个**非常友善**的巨人，没人告诉过他他在打仗。他扛着一根原木，因为别人给了他一根
原木。他走路的时候在看风景。

**数值依据**：高血高伤慢攻速（1.3 秒一下）。一个一秒半才挥一下的东西不是战士，是**工具**。

**剪影红线**：原木必须粗、必须扛在肩上、必须甩起来像没拿稳。

**剪影红线·修正**：原来写的"甩起来像没拿稳"**做不到，也不该做**。原木挂在 `armR` 上，胳膊绕 x
轴一摆，一根朝后的原木在相机里要扫过整个可见范围：前半周 60°，后半周缩成一截短桩——六帧六把
武器，读出来是穿帧，不是重量。重量只许表现为**滞后**，绝不许表现为**消失**（和弓兵的箭囊、盾兵
的"侧立闪"是同一条）。所以 `armR` 被钉死（0.08），木头的晃动只留 `GEAR_DRAG` 的拖尾。

**木头红线**（八次重做才试出来的，顺序就是重要性）：
0. **必须看得出它压在哪儿。** 这是第一版交出去被打回来的那条：那根木头从拳头斜着穿过去、擦着
   脑袋出去，**中间整段悬空**，于是它不是"扛着的"，是"举着的一根棒球棒"。东西只有在你能看见它
   **承重**的时候才叫扛。做法是在模型里写死一个承重点 `SHOULDER = (0.300, 0.060, 0.875)`——胳膊
   车削体的顶盖在 z 0.770，加一个木头半径 0.105，木头的底面正好贴在肩膀顶上——然后**拳头、肩
   点、远端三点共线，由代码构造保证**，后面任何一次改都不可能再把木头抬离他。
0b. **拳头必须抬到肩高。** 承重点有了还不够：手在胯高的时候，剪影仍然是"一条长斜线，底端一个
   拳头，中间什么都不碰"。把拳头提到承重点下方 0.40（`HAND_LOG = along(-0.40)`，肘弯折到木头
   底下），这个姿势没有第二种读法——人扛木板就是这么扛的，而且折起来的肘自带"这玩意很重"。
1. **不许横过脸。** 一条横杠压在脸上是 40 px 下唯一没法解析的东西。**把木头往下挪没用**——相机
   抬高 42°，往后走就等于往画面上走，压低只会把它拖到下巴上。第一版靠"推到头后面"解决；现在
   由第 0 条顺带解决了：压在肩上的那条线整根停在 x 0.22–0.38，而脑袋只有 0.21 宽，它从头的
   **外侧**过去，根本不进脸的范围。
2. **不许占宽。** `sprite.py` 把精灵面积锁死在已提交的那张上，木头多吃的每个像素都是从身体上
   扣的——**宽木头 = 小食人魔**。平放拉长那版渲出来 460 px 宽，他被压得比巨像还小。斜着扛，长度
   花在高度上（便宜），不花在宽度上（贵）：`DLOG` 取 50°，现在 302 宽（板上 131 CSS）。
3. **必须粗**：0.21 粗配 1.56 的身体，是老棒子的两倍半。这个尺寸下"沉"只能靠粗说。
4. **必须穿过拳头伸出去两头**：从手开始的木头是带柄的工具，不是别人塞给他的一根树。
5. **端面要露在看得见的那头**（上端，越过脑袋那头）。素的棕圆柱没有"端"，40 px 下读成一条棍；
   浅色锯口才让它变成一棵被锯倒的树。端面在下端白做了三轮——下端六帧全被胯挡住。
6. **留两个砍枝的疤**：四个像素的事，是原木和擀面杖的区别。

**他不许破功**：294 血不是"他很扛揍"，是"**他没注意到**"。九个人里只有他不在打仗，这个位置是
他一个人的——所以他**永远不看前方**。`peer=30 / gaze=-12`：头常年歪向侧上方，**每一帧都一样，
不随步子动**。40 px 下没人看得见眼睛，能读出来的只有**脖子的朝向**；"他在看风景"只能做成一个
恒定的转头，做成来回晃就只是个抽风的脑袋。这两个数字比他身上任何别的东西都值钱。

**队伍色红线**（第一版红蓝认不出来，原因不是颜色选错了，是**这块色根本没渲染出来**）：
1. 原来的 `loincloth` 腰布半径 0.25，而同高度的肚子半径 0.30——**腰布整个埋在身体里面**，真正
   到板上的只有底边两个像素。查这类问题永远先把装备的半径和身体曲线 `B.on_curve` 比一遍，不要
   先去调颜色。
2. 现在的 `kilt` 从头到尾比肚子宽（0.33 对 0.30），而且是 `team` 色，横跨他最宽的那一段：**这
   是全身唯一的一块大色**，40 px 下不可能漏看。
3. **大色块必须有边。** 上沿压一条 `leather` 腰带，否则队伍色在顶上渐隐进绿色里，读成一块脏，
   不读成制服。
4. 肩带收短成"肩到腰带"（原来一路拖到 0.41），因为腰带以下肚子比裙子窄，画在肚子上的肩带会被
   裙子吞掉。
5. 两条上臂环也改成队伍色：剪影**边缘**上的两个小记号，而边缘正是 40 px 精灵里眼睛真正落点。

**腿必须笨重**（第一版"看不出笨重"，踩过的坑都在这）：
1. **笨重不是大步。大步是闲逛。** 笨重是**小步**（`leg` 0.7→0.62，腿几乎错不开，因为抬腿费劲）。
2. **重量在腿的间距里，而间距是模型的事，不是姿势旋钮能给的。** 站距 0.190→0.225，腿粗
   0.150→0.168，脚也跟着放大：脚比胯宽，于是每一步都得把整个身体甩到支撑脚上面去。
3. 胯要**往下掉**不要往上跳（`limp` +0.022 → **-0.030**）。
4. 浮空长、落地狠：`stomp` 0.030→0.062，而 `stomp` 是三次方的，几乎全部变成落地那一下。
5. **`roll` 不许超过 1.7。** 试过 2.05，整个人读成在翻倒而不是在走路——"看着要摔"是 bug，不是
   性格。
6. `lean=-4`：挺胸往后仰一点，是扛重物的人在配重。

**木头不许晃**（用户原话："扛着的东西，走路时的晃动没那么大"，这条他是对的）：
`GEAR_DRAG['ogre']` 从 0.5 降到 **0.12**。0.5 是木头还在耳边悬空那版留下的；一旦它卡在拳头和
肩膀之间，**肩膀就是摁住它的那个东西**，它不可能再甩。现在它唯一的"重量"来自身体自己的 roll
带着它走——这也是实话：走一趟路的工夫里，那根木头就是他身体的一部分。

**怎么走**：**脖子撑不住脑袋。** 肩膀停了头还在动，头比身体晚三分之一拍——大头娃娃。胳膊过不去
自己的肚子，只能绕着走往外甩。整个人在两腿交错时悬在高点，落脚时一下砸平（跺步）。
**这是九个人里最该让人笑出声的一个。**

**怎么打**：原木抡过肩膀砸下去，砸完自己往前栽半步。

**怎么倒**：像一袋面粉。原木先飞出去。

## 六、术士 adept

`hp 99 / dmg 18 / rate 1.4 / range 3.0 / speed 0.65 / spawn 13 / rarity 2`

**他是谁**：**九个人里唯一一个在上班的**。别的八个在打仗，他在干活。中年，不老也不是学徒——
文件里曾经同时写着「很老」和「the apprentice」和「a young chibi wizard with blond hair」，三份
设定互相打架，现在统一成：一个受雇的职业人，谁出钱给谁打。这也解释了他为什么全身队伍色最多却
最不像个兵——**制服是发的，不是他的**。

**数值依据**：射程 3.0（全军最远），攻速 1.4（全军最慢），溅射 0.5。射程最远意味着他是**先手**
的那一个：敌人还没进任何人的射程，他已经开过火了。玩家是靠**站位**打他，不是靠操作。
最慢 + 最远说的是同一句话：**还来得及**。

**剪影红线**：尖帽子。那顶帽子比他本人高，是他在 40 px 下唯一的身份证。

**红线一·他必须是安静的那个**：
- 别的八个都是「由某种动作构成」的——巨魔是整个身体，投石手是弹袋，禁卫是膝盖。八个都在抖的
  时候，让第九个显眼的办法是**把动作拿掉**：步子小（leg 0.55）、胳膊几乎不离身（arm 0.35）、
  侧摆减半（roll 0.55）、不弹、不瘸、不驼。
- 唯一还在动的是**帽子**：`gawk` / `nod` 比肩膀晚三分之一个周期，所以人停了帽子还在甩。那半拍
  是他全部的生命力，而它之所以够用，正因为别的什么都不动。
- **删掉了原来的「拄杖一瘸一拐」走法**。那个走法在板上读出来不是性格，是「这个兵被打了 / 被眩晕
  了」——是 bug，不是角色。`GEAR_DRAG['adept']` 0.9 → 0.06 就是为了杀掉它。

**红线二·法杖必须垂直**：和弓箭手的「弓必须端平」同一类的规则。
- 一根竖直的杆 + 一顶比人高的尖帽子 = **两条平行竖线**，九个兵里没有第二个有这个剪影。
- 杖曾经前倾 16° 让水晶躲开帽檐。**斜着的杖读作拐棍**，拐棍就是上面那个瘸腿走法的来源。水晶改成
  往**上**躲（更高，高度是便宜的），不是往外歪，规则就保住了。
- 杖的材质不许用 `darkwood`：0.05 粗的 `#4a3020` 杆会和 `#2b1d14` 的描边融成一体，直接不再是个
  物体。改用和巨魔原木同一种 `wood` 木纹。
- 杖要**伸出去拿**（`B.arm(0.146, out=0.174, hy=-0.115)`），不能夹在肋下。贴着身体的杖读作「他
  手里刚好拿着根棍」；离开身体之后，杆和身体之间的那道缝才是告诉你「这是一条直的竖线」的东西。

**帽檐从 0.218 收到 0.198**：原来的帽檐比他自己的肩还宽，一次赔两样——42° 的相机把整圈帽檐的
阴影压在眼睛上（40 px 下就是一顶底下没人的帽子），而且它正好伸到法杖必须站的位置，水晶和帽檐
糊成一块。收窄 0.02 两样都买回来了。

**怎么走**：安静地走。见红线一。

**他不看前方**：`gaze` 取**正**值（低头）。巨魔是抬着下巴东张西望——他没注意到在打仗；术士是低着
头——他**不需要**看，三格之外问题就解决了，看不看都一样。`peer` 保持 0：球在他头顶的直杖上，
手边没有东西可以转头去看，而 40 px 下一个偏开镜头的脑袋只会把脸丢掉。

**怎么打**：法杖举起来，然后**一直举着**（`CAST` 已经是这样），球飞出去。他不收手。

**怎么倒**：先跪，帽子掉下来——帽子落地比人晚。

## 七、破城槌 colossus

`hp 632 / dmg 31 / rate 1.6 / range 1.1 / speed 0.45 / spawn 25 / rarity 3 / bldMult 2`

**他是谁**：全军唯一一个**不是活物**的单位。一根吊在 A 字木架下的撞木，架在一辆上漆的四轮车
上，没人推，自己滚。木雕不一定非得是人——这是全军对这句话答得最彻底的一个。

代号仍叫 `colossus`，中文名改了。原来是石巨人，石巨人有两个毛病：一是 `bldMult 2` 这条全军
独一份的数值要靠一整段"被唤醒的石头"去解释，机械不用解释；二是巨魔和巨像都是又大又慢又重，
在 40 px 下就是同一个兵画了两遍。现在它们不再是同一**类**东西了。

**为什么不是投石机**：投石机好看，但不成立。`range 1.1` 是贴脸距离（弓手 2.5，术士 3.0），而
`rules.ts` 里这个单位**根本没有 `ranged` 字段**，引擎永远不会给它生成弹丸——抛射动作会抡一圈
然后什么都不飞出去。`bldMult 2` 配 `range 1.1` 只说明一件事：走到墙根，砸。

**数值依据**：全军最高血（632，民兵的八倍）、最慢（0.45）、最贵（25）、攻速最慢（1.6）。一个
这么慢这么重的东西，走路的问题不是"怎么迈步"，是**"怎么停下来"**。

**剪影红线**：交叉的 A 字斜撑 + 一根贯穿整个造型的斜撞木。全军别的兵都是"竖杆加一个脑袋"，
只有它有斜线。撞木必须**两头都露出车外**——头在前下方，裹铁箍的尾在后上方——这条斜线就是读数。

**红蓝在哪**：**整辆车身**就是队伍色，上面的木架和撞木全是本木色。中间试过屋顶（读成狗窝）、
试过前倾挡板（悬空、压着羊头、而且正好挡在撞木的冲程上）。车身是唯一一个既是最大色块、
又在剪影下半部被四个轮子框住、还**本身就是结构**的位置——没有任何东西是贴上去的。
四个轮毂也是队伍色，在四角重复一遍。
车厢盖是**一个低矮的拱顶**，不是平板——这一条是被渲染器逼出来的：`sprite.py` 的内描线在"某点
附近有东西比它近 0.012 以上"时上墨，而一块大平顶和视线成 48 度，深度刚好每单位爬 0.74，落在
笔刷里正好是 0.0121，骑在阈值上。于是一半像素描一半不描，顶面出来是一张随机裂纹网，**而且
逐帧图案都不同——走起来会闪**。曲面没有单一梯度，只有细细一圈落在阈值附近，那一圈描出来就是
形体暗部。顺带它还接光，把顶面和侧面分开了，平板一直没做到这件事。

**怎么走**：两根轴每帧转整整六分之一圈，正好闭合六帧循环；每条胎面上**五个凸齿**对六帧，帧帧
落点不同，剪影就一直在变——20 px 下剪影就是全部，读出来的是"哐当"。车身在辙里颠三度，撞木
比车身**慢一拍**，这一拍是唯一在说"它是吊着的，不是焊死的"。

**怎么打**：**整根撞木前后平移，不是荡。** 这是这台车唯一真正难的地方。吊在绳上的撞木，真实
的运动是沿着自己那条线前后滑；一旦让它绕脊木转，羊头就跑到弧线的远端去了，那里转一度几乎全
是**上下**位移——出来的四帧读起来就是投石机甩臂，试过，34 度和 20 度都一样坏。
解法是把支点放到车底下一米（`RAM_PIVOT = -1.00`）：力臂两米多，转九度在羊头那里就是一段
几乎水平的直线，`pose.apply()` 只会转不会移，这个地下支点就是用转来伪装平移。代价是绳子不能
跟着动，所以绳子归框架、撞木归 `ram` 组——它们在动画里会轻微错位，这是故意撒的谎，比羊头飞
起来便宜得多。往后抽九度、往前捅九度，车身反着颠十度：车先撑住，再被撞木带着往前蹿。
羊头正前方之所以什么都不放，就是为了空出这条冲程——挡板放在那里，等于撞木第一下砸自己的甲。

**怎么倒**：整台车往前栽，一次倒完——它不是跪下，是散架。

## 八、飞龙 drake

`hp 272 / dmg 16 / rate 0.9 / range 2.2 / speed 1.0 / spawn 24 / rarity 3 / splash 0.6`

**他是谁**：一条**小**龙。全军最快（1.0），攻速最快（0.9），但伤害只有 16——他不是威胁，他是
**烦人**。一条还在练的龙，飞得不稳，喷火喷得太开心。

**数值依据**：最快 + 最高攻速 + 最低单发伤害 + 溅射。这是一个"到处乱窜、到处点火、谁都打不着
他"的角色。

**剪影红线**：**他是棋盘上唯一一个不碰地的。** 身体横着、顺着飞行方向躺平，爪子是剪影的最低点
并且悬空——肚子底下那条缝就是"他在飞"的全部证据。翅膀张开时必须明显比身体宽。

他曾经是站着做的：两只脚踏在板上、脖子从肩膀直直往上长。那样在 40 px 下不是龙，是一只披斗篷的
小熊——翅膀读成披风，喷火读成鞠躬。后面所有毛病都是这个姿势带出来的，改姿势就全好了。

**队色在翅膀上**：龙没有外袍，膜是全身最大的一块平面，也是 40 px 下唯一能说清这是谁家龙的东西。
所以拍翅幅度有上限（±18°）：再大，上行程翅膀立成侧面，半个循环队色就只剩一条边。

**怎么走**：**他根本不走。** 没有步子，只有一拍翅膀——身体随之起落，而且比翅膀慢四分之一拍，
收起来的后腿和脖子跟着晃，什么都不承重。一个循环一拍，不是两拍：六帧两拍每拍三帧，三帧的东西
是闪烁不是动作。

**怎么打**：脖子先往后收并抬头，然后整个头顺着飞行方向甩出去喷，机头略微下压——像俯冲扫射，
不是鞠躬。

**怎么倒**：**从天上掉下来。** 他没有后跟可供向后仰倒，所以是先轻轻栽头、然后**翻身**——
翅膀压到身下，浅色的肚皮翻上来。这块肚皮是棋盘上任何活着的东西都不会露出来的。

## 九、城堡卫兵 guard（弩手，开局唯一的防线）

`hp 320 / dmg 14 / rate 0.7 / range 2.4 格 / regen 12 / respawn 12s`（`rules.ts` 的 `GUARD`，
不在 `UNIT_KEYS` 里——他不是卡，是城堡自带的）

**他是谁**：城门口那位。白胡子、高筒帽、一身礼服——看着像个摆设，手里却是一把上了弦的弩。
`sim/guard.ts` 从写下来的第一天起就是 `fire(..., 'bolt', PROJ.bolt)`：他一直是远程，
**是美术在骗人**（以前给他做的是长戟，一把近战长柄武器）。

**数值依据**：DPS 14/0.7 = **20**，比食人魔（21/1.3 ≈ 16）还高；射程 2.4 格，只比弓兵的 2.5
差一点点。他还有 regen 12、脱战 3 秒回血、倒下 12 秒复活。**开局的防护一点都不弱**——玩家
感觉弱，是因为他手里拿的是近战武器，看起来不像能还手。所以这一版只改美术和动作，
`src/sim` 一个字没动。

**剪影红线**：**高筒帽 + 一把横着的弩。** 弩是个"十"字：弓臂是全身最长的一条横线，弩身斜着
从右下穿过它。这条规矩是四版试错换来的——

- 弩摆平（弩身顺 −y、弓臂顺 x）：yaw 34° 下 x 投影 0.83、y 投影 0.56，两根都落在近水平的
  屏幕线上，叠在一起成了一块带棱的板子，**读成火枪**。
- 弓臂、弦、弩矢都用 `B.line` 珠链：三条平行虚线挤在一小块里，**读成渔网**。
- 浅色裤子 + 浅色弓臂 + 浅色弦挤在同一角：**读成一团糊**。裤子改成 `leather`（深），靴子
  留 `boot`（比 leather 浅一档，不然脚成了一个洞），全身只剩弩是亮的。
- 弩矢做成一整根躺在槽里、与弩身平行的浅色长杆：**读成枪管**。只留弦前面那一小截箭头。

- 弩沉在腰（`FIST = 0.252`）：那一带腰带、扣子、大腿本来就挤，弩**读成挂在身上的行李**。
- 抬到胸口但两手裸前臂横过胸膛：前臂长 0.47、粗 0.042、浅肤色，成了**两根浅色大棍压在弩上**，
  弩整个消失在自己的胳膊里。
- 倾角靠眼睛定（−14°）：**算出来才知道它投到屏幕上是 −1°**，和弓臂的 +12° 只差十二度，等于贴在
  一起，所以无论怎么配色都还是一块板。

投影公式现在直接写在 `model_guard` 的注释里，以后不用再猜（yaw 34°、仰角 18°）：

```
right = 0.829·dx − 0.559·dy      up = 0.173·dx + 0.256·dy + 0.951·dz
depth = 0.532·dx + 0.788·dy − 0.309·dz        （越小越靠近相机）
```

最终几何（`troops.py` 的 `model_guard`）：扳机握点 `(0.200, −0.060, 0.310)`。弩身方向
`(−SWING, −1, −tanTILT)`，`SWING = 0.18`、`TILT = −52°`——**水平面上也拧了一下**，不只有上下
倾角。弩身投到屏幕是 **+66°**，和弓臂的 +12° 差五十四度。整把武器的每一个长度再乘 `W = 1.36`
（缩放中心是握把，两只手自己跟着加长的前托往外挪），因为按原尺寸它的弓臂跨度只有 0.37 个身宽、
和他本人一样宽，用户的原话是「看起来就像拿了一个玩具」。

**口必须朝上。** 巡逻的弩手把口举着，随时能射，不会指着自己的靴子。但相机是**俯视 18°**，
整条刻度被压到地平线底下：按上面的 up / right 公式，`tan TILT < −0.302`、也就是 `TILT < −17°`
之后，口在屏幕上才开始往上抬，不管它在世界里已经翘了多少。−52° 在世界里是抬 52°，屏幕上读 +66°。

**抬倾角不一定变短。** 往上抬会让弩身转向镜头、在屏幕上缩短，这是真的；但过了大约 −30° 之后，
它在屏幕上多出来的高度把长度挣了回来，和弓臂的夹角也跟着一起张开：−39° 是 0.49 长、38° 夹角，
−30° 只有 0.42 长、21° 夹角。**最终停在 −52°**，因为 38 度的夹角在棋盘尺寸上还不是十字、是一把
步枪；54 度才是。再往上到 −60°，箭头就和帽缨齐平了。

**抬起来之后三件事全得跟着改**，这是这一版踩的三个坑：

- **握点必须整体下移。** 口朝上、握点还在胸口 0.430，弩首直接顶到白胡子和帽檐，十字挤在脑袋
  边上，整把弩读成一支步枪。落到 **0.310**（胯高）、再往外挪到 x **0.200**，十字就落在身体
  右侧的空背景里。前托握点仍在胸口高度（0.409），"端在胸前"这句话没丢。
- **弓臂不能太长。** 第一版留着原来的 ±0.262，弓臂成了贯穿全身的一条长横杆，弩身只是挂在
  上面的短柄——还是步枪。收到 ±0.225 才是弩的比例（弓臂宽度略小于弩身长度）。现在是
  `SPAN = 0.245 * W`，跟着 `DROOP = 0.125 * W` 一起提上来的。
- **两条弓臂必须是同一条镜像过来的。** 臂尖挂在弩首 `nose` 上，左右只差 SPAN 的正负号，不要
  为了屏幕上的观感去挪其中一边。早先的版本把弓臂根挂在顺着弩身往回退 0.195 的一个点上、再沿
  x 推 0.095 把弩首推回弦的中点，屏幕上是对称了，模型里两条臂变成 0.368 对 0.536——**长的那条
  长了 46%**，用户一眼就看出来了。屏幕上剩下的 1.195 是相机 up 向量里的 `0.173*dx` 把横杆躺成
  12 度造成的，场景里每根直的东西都这样，不要去修它。
- **弓臂和弦之间那块天光只有 DROOP 能开。** 弩首到平弦的距离是 `0.506*(沿弩身回退) +
  0.931*(下沉)`，SPAN 在投影里精确抵消——加宽弓臂一个像素的洞都买不到。代价是弓臂和弩身差 27°
  不成直角，这是一把反曲很深的弩，也是这件武器现在仍然在撒的唯一一个谎。
- **肘的高度规则整个反过来了。** 弩身朝下时，肘要放低，前臂才斜着爬上去和它交叉；弩身朝上
  之后，低肘的前臂变成 +35°，几乎贴着 +50° 的弩身躺下去，又是"蓝管子压在弩上"。前托那条
  手臂的肘要**跟着抬到 0.380**，前臂才接近水平（屏幕 +11°），和弩身交叉。扳机那条手臂的肘
  留在胯边 0.330，短前臂向上折到扳机，屏幕 +121°，几乎垂直切过弩身。

弩身长 0.510，枪托只有 0.090，前托握点在 0.175 处。弓臂根部在 **0.235**（不是靠近弩首的 0.330）：
根部太靠前，两条弓臂和弦之间只差十六度，**三条共线的浅色线就是一条线**，弩读成一根棍加一个深色
疙瘩。退到 0.235，弓臂张成人字，弦才在后面割出一块三角形的天光——**那块三角就是"弩"这个字的
全部**。弓臂左右各 ±0.225、半径 0.016，全部实心 `rod`，不用珠链。

**手是真握着的**，这件事有四层：`body.arm` 加了 `hz`，拳头能抬到胸口，**前臂跟着重算成"从肘指
向拳"的一根杆**（不然手上去了胳膊还指着地）；两只拳头都比弩身轴线**往前 0.022**，按上面的 depth
公式正好浮出木头表面压住它（齐平的话球吞杆、杆也吞球，谁都没握住）；每只手处的弩身上加一圈
`leather` 缠带，让"握在这儿"有个明确的明度变化；前臂是 `fore='team'` 的**长袖**、粗细 0.030——
横过胸口的那截必须是深色，屏幕上只留弩和两只手是浅的。

**手肘必须单独给**（`body.arm` 的 `elb`）。肩膀在 |x| = 0.15，外袍宽 0.175——**肩膀在袍子里面**，
所以从肩直接拉一根杆到对侧的手，整个中段埋在躯干里，渲出来是"肩 + 一截空白 + 悬空的手"，
手臂看着是断的。`elb` 把手臂拆成两段，经过一个在袍子外面、又靠前的肘。

**袖口还得补一颗球。** 袖子是个 lathe，底下是 z = 0.400、半径 0.056 的**一圈敞开的平口**，
而上臂是半径 0.030 的杆斜着从里面穿出来：细杆穿过宽平口的地方，轮廓会往里**跺一刀**，放大了
就是肩膀上那道接缝。在平口处埋一颗同宽的球（`ball(0.058, sleeve, (x, 0, 0.404))`，z 向压扁
0.86），平口被封住，杆有了一个圆窝可以钻出来，胳膊是从袖子里**收出去**的，不是被袖子切断的。

**怎么走**：**正步。** 腿抬到下巴（`leg=1.75`、`march=1.0`），胸挺出去，头钉死不动，
**而那把弩一根毛都不动**（`arm=0.1`、`GEAR_DRAG=0.05`）。笑点是对比：腰以下在阅兵，
腰以上冻住。两只手都握在一把端平的弩上，所以"手不动"同时也是真的。

**怎么打**：`STYLE='aim'`——别人的攻击是肢体走出去，他的是肢体**不走**，然后一脚后坐。
`AIM = (-5, -9, 14, 5)`，两条胳膊走同一条曲线（弩挂在 armR 上，左手扶在前端，只动右臂
弩会从左手里走出去）。14° 比真弩的后坐大，必须大：40 px 下后坐那一帧是"箭射出去了"的
唯一证据，箭本身是 sim 画的（`PROJ.bolt`）。

**怎么倒**：僵直着倒，像一块板子。

## 队伍色怎么用

机制：`prim.py` 的 `TEAM = {'blue': '#1d58d8', 'red': '#cc2216'}` 是一种叫 `team` 的材质，
**蓝红各渲一遍**，不是运行时叠色。另外 `src/view/unitView.ts` 的 `baseCtx` 给每个兵脚下画了
一块队伍色木底盘——敌我识别有两道保险，不全靠衣服。

因此有一条规矩：**九个兵共用一个色相，不许各发各的颜色。** 敌我是棋盘上第一眼要读的东西，
九种色相会把它彻底打散。辨识度走另外两条轴：

1. **队伍色穿在哪**——胸口、帽子、斜挎带、底盘，位置本身就是身份。
2. **非队伍色的材质和明度**——这才是区分同体型角色的主力。

民兵 / 投石兵 / 弓兵是同一具身体的三个尺寸，之前三个都是"胸口一块队伍色的棕衣小人"，
40 px 下分不开。现在按明度排开：

| | 队伍色在哪 | 身体 | 一句话 |
|---|---|---|---|
| 民兵 | 斜挎带（胸前对角） | 本色亚麻，全军最浅 | 浅色的那个 |
| 投石兵 | 帽子（剪影最顶上） | 深皮背心 + 浅裤 + 光胳膊 | 戴亮帽子的那个 |
| 弓兵 | 整件上衣 + 斗篷 | —— | 整个人是队伍色的那个 |

两条教训，别再犯：

- **斗篷不能当队伍色标记。** 斗篷挂在 +y，背着相机，32 度偏转下几乎看不见。
- **深色躯干安全，深色靴子不安全。** 躯干被皮肤和裤子围着，读成一个形状；靴子贴着描边，
  读成一个洞（`prim.py` 的 `boot` 比 `leather` 浅就是为了这个）。

## 怎么用这份文档

每个角色有三行必须过的验收：

1. **剪影红线**有没有被破坏（弓是不是还平的、盾是不是还最大、帽子是不是还最高）。
2. **40 px 下还认不认得出他在干什么**——缩到 40 px 看一眼，分不出就是没做到。
3. **他有没有做别人也在做的事**。九个人不许有两个用同一种方式晃。

调整顺序按稀有度，从民兵开始：民兵是基准，其他八个都是"和民兵不一样"才成立的，基准没定住，后面
全是空中楼阁。

动作的实现位置：`tools/art3d/pose.py` 的 `SIG` 表（走路）、`STYLE` / `THRUST` 等常量（攻击）。
每个角色一次只改一个，渲完看了再改下一个。
